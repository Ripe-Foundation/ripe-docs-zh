# 抵押资产

从股票代币开始，再加入 WETH、稳定币和质押 ETH。Ripe 把它们视为一个投资组合，共同支持一笔 GREEN 贷款，每种资产贡献自己的条款。不用每种资产开一个金库，也没有闲置资本。您的抵押品只支持您自己的贷款，不会支持别人的贷款。

> **实时条款以链上为准。** 支持哪些资产、它们的 LTV、存款上限及启用了哪些可选功能，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 一个投资组合，一笔贷款

大多数 DeFi 借贷迫使用户二选一。隔离市场让每种资产对应一笔贷款——五种资产、五个仓位、五项清算风险。资金池式借贷则让您的存款支持所有人的贷款，因此只接纳少量“安全”代币。

Ripe 两者都不采用：

```
您的投资组合                         Ripe
┌──────────────────────────┐    ┌──────────────────────────┐
│ 股票代币       60% LTV   │    │ 一笔 GREEN 贷款          │
│ WETH           70% LTV   │ ─> │ 加权利率和限制           │
│ 稳定币         80% LTV   │    │ 一个健康指数             │
│ 质押 ETH       70% LTV   │    │ 风险只属于您             │
└──────────────────────────┘    └──────────────────────────┘
```

每种资产保留自己的 LTV、利率和阈值；系统按借款能力把它们合并为一个仓位。详见[加权债务条款](02-borrowing.md#加权债务条款详解)。

## 以股票代币作抵押

Ripe 按一比一保管股票代币：存入 10 枚，仓位记录 10 枚。用它们借入 GREEN 从不意味着卖出、出借或动用代币——股票上涨，抵押品价值也随之上涨。每种代币由其价格源定价，已经包含公司行动影响；休市时，只要仍在价格源的新鲜度窗口内，就会沿用最后一个价格。

股票代币的所有专属细节——保管、定价、交易时段、公司行动、发行方条款，以及究竟哪些事件可以移动代币——都集中在 [Ripe 上的股票代币](00-stock-tokens.md)。

## 资产类别

治理添加资产后，Ripe 可以支持任何具有可靠价格源的 ERC-20。条款按资产设置——稳定币 LTV 高于波动性代币——以下每个类别代表一个层级，而不是当前已启用资产清单。

**1. 代币化股票与其他现实世界资产。** 当前包括股票代币；未来还有上链的债券、基金和大宗商品。部分资产带有发行方层面的转账规则，Ripe 会遵守。

**2. 稳定币。** USDC 和其他美元代币，以及生息稳定币。因价格波动很小，通常拥有最高 LTV。

**3. 蓝筹加密资产。** WETH、WBTC 及其他流动性深厚、价格源可靠的成熟代币。

**4. 生息资产。** 质押 ETH（stETH 类代币）、LP 代币和金库份额。它们在支持贷款的同时继续赚取收益——Ripe 的份额核算会把收益计给您。

受支持的 [Underscore](https://underscore.finance/) 金库份额就是一个例子：存入 Ripe 后仍在原金库内继续赚取收益。[Earn 金库利率折扣](02-borrowing.md#underscore-earn-金库集成)适用于金库自己借款，而不是您存入其份额时。

**5. 新兴资产。** 历史较短的新代币会采用保守条款——较低 LTV，或 LTV 为零。

## 存入如何运作

### 金库类型

每种资产会分配到一个与其代币行为相匹配的核算金库。您只需存入，Ripe 会选择合适金库。

**简单 ERC-20 金库**——用于普通代币，包括股票代币。您的余额就是存入的准确代币数量。这类金库要求严格：只有准确数量全部到账后，存入才会记账；只有准确数量能够全部转出时，提取才会完成。如果代币拒绝转账，交易会失败，而不会只完成一部分。

**弹性供应与份额金库**——用于余额会增长的生息代币。您持有金库余额的一定份额，因此收益归您所有。这类金库提取时允许舍入尾差，并按实际转出数量记账。

**治理金库**——锁定 RIPE 以获得[治理](../governance-and-economics/02-governance.md)权力。不是抵押品。

**稳定池**——存入 sGREEN 或 LP 代币，以低于市场价格[买入被清算抵押品](../earning-and-rewards/02-stability-pools.md)。永远不是抵押品。

**未来金库类型**——NFT 和其他需要独立保管或核算方式的资产。目前尚无 NFT 金库；未来新类型可以接入，而无需修改现有金库。

### 存款限制

存款限制按每种资产设置，并以代币单位计量：

* **单用户上限**——一个账户在该资产金库中最多可持有的数量。可存金额 = 上限减去当前余额。
* **全局上限**——该金库总共最多可持有的资产数量。上限让资产在成为 GREEN 主要支持之一前逐步建立信任。
* **最低余额**——防止形成尾差仓位。存入或提取后，余额必须为零，或至少达到最低值。
* **金库和资产数量上限**——限制一个账户最多使用多少个金库，以及每个金库最多持有多少种资产。

治理会随时间提高或降低这些限制。

## 提取资产

只要仓位保持健康，随时可以提取。没有排队和等待期，可以部分或全部提取。

可提取数量取决于资产 LTV、包含利息的当前债务，以及其他抵押品能覆盖多少。Ripe 会保留 1% 缓冲：提取后，债务必须不超过最高借款能力的约 99%。

**示例：**

```
已存入：价值 10,000 美元的 ETH，LTV 为 70%
已借入：5,000 GREEN

所需抵押品 = 5,000 × 1.01 ÷ 0.70 = 7,214.29 美元（1% 缓冲）
可提取 ETH 价值 ≈ 2,785.71 美元
```

一旦超过最高 LTV，所有提取都会被阻止——包括 LTV 为 0% 的资产——直到还款或增加抵押品。代币也可能通过赎回（进入赎回区后）或清算（超过清算阈值后）离开。详见[关键安全阈值](02-borrowing.md#三项阈值如何协同直观指南)。

## 存入期间赚取收益

启用奖励后，存款可以通过积分系统赚取 RIPE：

```
积分 = 存款价值 × 持有区块数
份额 = 您的积分 / 总积分
奖励 = 您的份额 × 释放量
```

时间和规模同等重要。存款人类别、投票选定加成，以及稳定池与治理金库奖励，详见 [RIPE 奖励](../earning-and-rewards/03-ripe-rewards.md)。

## 委托

您可以允许另一个地址操作自己的仓位。权限分为两类：

* **账户级，默认关闭：** `canAnyoneDeposit`、`canAnyoneRepayDebt`、`canAnyoneBondForUser`。任何人都可代您增加抵押品、还款或购买债券——这些操作都无法把价值转出。
* **按委托人设置：** `canWithdraw`、`canBorrow`、`canClaimFromStabPool`、`canClaimLoot`。授予特定地址，并可随时撤销。

即使由委托人触发，提取资产也始终进入您的钱包。不过，拥有借款或提取权限的委托人仍可能损害您的仓位——借到上限，或提取维持健康所需的抵押品。只应委托给您控制或信任的地址。

适用于团队金库、自动化策略和智能钱包设置。

## 资产特定权限

* 某些代币附带发行方层面的规则——白名单、黑名单、暂停——Ripe 无法覆盖。
* 治理可以要求某种资产采用白名单；如需批准，应用会提示。
* 每种资产采用哪种退出路径——赎回、稳定池、拍卖——都按资产设置。

## 为什么存入 Ripe

* **每种资产都能发挥作用。** 股票代币、加密资产、稳定币、收益仓位——一笔贷款。
* **抵押品继续赚取收益。** 质押资产和金库仓位在支持债务时仍可复利。
* **风险只属于您。** 抵押品只支持您的贷款，而不是共享资金池。
* 普通抵押品没有锁定期，存款还可获得 **RIPE 奖励**。

不要卖出股票，让它们开始工作。
