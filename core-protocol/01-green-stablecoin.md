# GREEN：更努力工作的稳定币

您的 USDC 只是躺在那里。DAI 每增加一种资产就需要新金库，LUSD 只接受 ETH。

GREEN 的设计与众不同。用整个投资组合——股票代币、ETH、稳定币、收益仓位——共同支持一笔贷款。以 [sGREEN](../earning-and-rewards/01-sgreen.md) 持有，就能赚取协议收入；放入[稳定池](../earning-and-rewards/02-stability-pools.md)，就会以低于市场价格买入被清算抵押品。还有六项机制把它拉回 1 美元。

这就是不再问“如何再造一种稳定币”，而是开始问“稳定币究竟应该如何运作”之后得到的答案。

> **实时条款以链上为准。** 资产、LTV、利率、费用及启用了哪些可选功能，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## GREEN 为何存在

### 现有稳定币借贷的问题

**隔离仓位（MakerDAO/Liquity）：** 每种资产一个金库。五种资产，五笔贷款，五项清算风险。

**风险池化（Aave/Compound）：** 只接纳“安全”资产。您的抵押品支持所有人的贷款，而别人的坏账会成为您的问题。

**隔离货币市场（Morpho/Euler）：** 每个交易对一个市场，每个市场都需要自己的出借人。同样的碎片化，流动性更薄。

### Ripe 的方案：统一多抵押品借贷

```
传统方式：ETH → DAI 仓位 1
          WBTC → DAI 仓位 2
          USDC → 无法使用

Ripe：    股票代币 + ETH + 稳定币 + 收益仓位
          ↓（全部合并）
          一笔采用加权条款的 GREEN 贷款
```

您存入的每种受支持资产都以自身条款共同支持同一笔 GREEN 贷款。风险只属于您：其他人的爆仓不会影响您的仓位。

### 互补，而不是竞争

其他协议擅长创造收益，Ripe 则把它们的生息代币变成抵押品。代币获得支持后，会在支持贷款的同时继续赚取收益：借贷市场代币继续累积利息，金库份额继续复利。在那里赚取收益，在这里借款。

## GREEN 如何运作

### 通过借款创造

借款是 GREEN 产生的主要方式：

1. **存入抵押品：** 任意[受支持资产](03-collateral-assets.md)——[股票代币](00-stock-tokens.md)、WETH、稳定币、收益仓位。
2. **借入 GREEN：** 以抵押品为基础铸造新的 GREEN，最高不超过各资产 LTV。
3. **支付利息：** 按仓位加权利率支付；如果 GREEN 需要维护，还会加上[动态调整](02-borrowing.md#dong-tai-li-l)。
4. **发起费（Daowry）：** 借款时一次性从 GREEN 中扣除。它会进入 sGREEN 持有人；治理可以把一部分分配给 RIPE 回购额度，默认全部发送给 sGREEN。

**示例：**

```
您的统一投资组合：
- 价值 10,000 美元的股票代币（60% LTV = 6,000 美元借款能力）
- 价值 10,000 美元的 WETH（70% LTV = 7,000 美元借款能力）
- 价值 10,000 美元的稳定币（80% LTV = 8,000 美元借款能力）
- 价值 4,000 美元的收益仓位（70% LTV = 2,800 美元借款能力）

总借款能力：23,800 GREEN
一笔贷款，一个利率，一个需要关注的数字
```

借款不是唯一的铸造来源。以下情况也会创造 GREEN：

* 全协议累积利息被实现时——在下一笔借款发生时一并铸造，并发送给 sGREEN（以及已设置的回购分配）；
* 有人通过 [PSM](#id-6.-mao-ding-wen-ding-mo-kuai-psm)，以其储备稳定币铸造；
* 金库稳定器向参考资金池增加 GREEN 流动性；
* 金库在流动性合作中，以合作伙伴资产为基础铸造 GREEN；
* 向执行清算的守护者支付报酬（见下文）。

### 通过还款销毁

还款时 GREEN 被销毁，因此供应量会随真实借款需求扩张和收缩：

1. **发送 GREEN：** 返还借款本金和利息。多付部分会退还。
2. **永久销毁：** 用于偿债的 GREEN 被销毁。
3. **释放抵押品：** 债务越少，可提取空间越大。

GREEN 在以下情况也会被销毁：赎回抵押品；稳定池使用 GREEN 或 sGREEN 结算清算；您自己的 sGREEN 通过去杠杆偿还债务；通过 PSM 赎回；金库从参考资金池移除 GREEN。

### 跨链代币移动

GREEN 通过销毁并铸造模式跨链：发送数量在源链销毁，再在目标链为您铸造。每条链的部署都会指定哪个跨链桥资金池可以在该链铸造。

## 六大稳定支柱

GREEN 通过六项触发条件不同的机制以 1 美元为目标。其中多项属于赎回或兑换路径，因此 GREEN 偏离锚定时，套利者不止有一种方法把它推回去。

### 1. 超额抵押基础

* **每笔贷款都超额抵押：** 每种资产的 LTV 限制可借金额，更安全的资产拥有更高 LTV。
* **投资组合效应：** 股票代币、ETH、稳定币和收益仓位不会同时同幅下跌。
* **每次操作都重新定价：** 每次借款、提取或清算，都会用实时[预言机价格](06-price-oracles.md)重新估值整个仓位。
* **先经过警戒区：** 赎回和去杠杆先于[清算](04-liquidations.md)。

### 2. 动态利率响应

GREEN 走弱时，借款成本上升，促使借款人买入 GREEN 还款——买盘会支持锚定。Ripe 从 GREEN 参考资金池读取信号。每当有人使用协议，系统都会记录资金池中 GREEN 占比的快照；利率信号采用这些快照的按时间加权平均值，并对每个相邻快照区间取较低读数，因此单次尖峰无法提高任何人的利率。超过危险触发点后，基础利率上方会增加一项加成；资金池处于危险状态越久，加成越大，但受硬上限约束。危险计时只有在资金池持续安全一段时间后才会重置，不会因第一个安全读数立即清除。间隔过长的区间会被剔除；如果最新快照已经过期（协议安静时没有新快照），就完全没有信号，所有人只支付基础利率。

完整机制见[动态利率](02-borrowing.md#dong-tai-li-l)。

### 3. 直接赎回机制

仓位进入[赎回区](04-liquidations.md#shu-hui-huan-chong-qu)后，任何 GREEN 持有人都能针对它赎回：按 1 美元支付 GREEN，按预言机价格取得抵押品。没有折扣，也没有罚金；借款人债务减少相同金额。金额向下取整。

```
GREEN 市价为 0.97 美元？流程如下：

1. 套利者发现 3% 折价
2. 在市场花 9,700 美元买入 10,000 GREEN
3. 从赎回区仓位赎回价值 10,000 美元的抵押品
4. 扣除费用和滑点前，毛利差为 300 美元
5. 买盘压力把 GREEN 推回 1 美元附近
```

必须有人提交交易，而且只有存在赎回区仓位时才可进行——市场平静时可能没有可赎回目标。它会在压力把仓位推向清算时启用，而这正是 GREEN 最需要支持的时候。

### 4. 稳定池赎回机制

第二条赎回路径通过[稳定池](../earning-and-rewards/02-stability-pools.md)运行：

* 资金池持有在清算中买入的抵押品。
* 治理启用后，GREEN 持有人可以按预言机价格，用 1 GREEN 赎回价值 1 美元的抵押品。
* 只有资金池持有可领取抵押品时才可进行——没有近期清算，就没有资金池赎回。

```
GREEN 市价为 0.96 美元？有两种赎回选择：
1. 直接赎回（如果有仓位处于赎回区）
2. 资金池赎回（如果资金池持有被清算抵押品）
```

两条路径都会在市场压力中得到更多容量：清算越多，资金池抵押品越多，对 GREEN 的需求也越多，而且恰好发生在最需要的时候。

### 5. Endaoment 金库运作

[Endaoment](07-endaoment.md) 是协议自有金库。债券和 Reserve Engine 配额付款会进入其中，由治理部署至收益、流动性和锚定维护。

**稳定器**

```
GREEN 低于锚定（池中 GREEN 多于配对资产）？
→ 从资金池取出 GREEN 流动性
→ 在已记录资金池债务范围内销毁
→ 资金池重新平衡，价格逐步回到 1 美元

GREEN 高于锚定（池中 GREEN 少于配对资产）？
→ 增加 GREEN 流动性，优先使用金库 GREEN
→ 铸造其余部分，记作资金池债务，但不超过上限
→ 资金池加深，价格逐步回到 1 美元
```

每次稳定器操作都由治理提交，不按定时器运行。每次只调整失衡的一部分，不会一步强行恢复精确 50/50；而且只有当金库净头寸不会变差时才执行。铸造前先使用金库已有 GREEN，并在达到资金池债务上限时停止。

**流动性管理**

* **任何受支持场所：** 通过已注册集成进行兑换、添加和移除流动性及收益存款。
* **合作伙伴计划：** 以合作伙伴资产为基础铸造 GREEN，并与其配对以加深市场。该铸造不受稳定器上限约束；资金池未接收的 GREEN 会被销毁。
* **自我供给：** 这些操作产生的费用和收益留在金库中。

### 6. 锚定稳定模块（PSM）

无需复杂套利策略。PSM 在一笔交易中按 1 美元，把 GREEN 与其储备稳定币（部署时固定为一种稳定币）互换，具体方向取决于治理启用了哪一侧。

* **铸造 GREEN：** 存入储备稳定币，按 1:1 接收 GREEN（如设置费用则扣除）。如果选择 sGREEN，只要铸造金额超过 1 GREEN，全部金额都会自动包装成 sGREEN。
* **赎回 GREEN：** 销毁 GREEN 或 sGREEN，按 1:1 接收储备稳定币（如设置费用则扣除）。
* **无需进入特定区域：** 与赎回不同，PSM 不需要有仓位处于赎回区，也不需要资金池持有抵押品——只需要储备。

```
GREEN 市价为 0.97 美元？
1. 在 DEX 花 9,700 美元买入 10,000 GREEN
2. 通过 PSM 赎回 10,000 枚储备稳定币
3. 扣除费用前，毛利差为 300 美元
4. 您的买盘压力恢复锚定

GREEN 市价为 1.03 美元？
1. 通过 PSM 用 10,000 枚储备稳定币铸造 10,000 GREEN
2. 在 DEX 卖出，得到 10,300 美元
3. 扣除费用前，毛利差为 300 美元
4. 您的卖盘压力恢复锚定
```

**细则**

报价采用储备稳定币的预言机价格与 1:1 中对您较不利的一项。每个时间区间的限额会限制可铸造或赎回数量，治理也可在上线期间要求白名单。受认可的 Underscore 金库不受限额、白名单和费用约束，并在赎回时获得更有利报价。如果治理设置了收益金库，PSM 会把全部闲置储备存入其中，并在赎回需要时取回。赎回最高不超过总储备，包括闲置部分和金库内部分。

结论：GREEN 脱锚时，PSM 是缩小差距的最短路径。

## GREEN 生态系统的其他功能

### 坏账处理

如果极端状况让账面出现坏账，[债券](../governance-and-economics/03-bonds.md)付款会清理坏账，而对应部分支付的 RIPE 会与普通债券配额分开核算。治理以全协议政策在所有链上执行 RIPE 的 10 亿上限；坏账恢复是唯一可以超出上限发行 RIPE 的情况——由持有人共同承担缺口，而不是让 GREEN 缺乏支持。详见 [RIPE 代币经济学](../governance-and-economics/01-ripe-tokenomics.md)。

### 全协议集成

* GREEN 是 Ripe Protocol 中唯一可借入的资产。
* 清算债务以 GREEN 结算：拍卖用 GREEN 支付；稳定池使用其 GREEN 和 sGREEN 付款，或将非 GREEN 资产交给金库。
* [去杠杆](05-deleverage.md)是另一种减债方式，会使用您的 sGREEN 和稳定币仓位。

### 守护者网络保护

* 仓位超过阈值后，任何人都可触发清算；机器人全天候监控。
* 守护者奖励默认铸造为 sGREEN（守护者可要求 GREEN；尾差以 GREEN 支付），并加入借款人债务。
* 每次清算过程只收取一次清算费，不会在每次重试时重复收取。
* 快速清算可以把坏账降到最低。

## GREEN 在 Ripe Protocol 中的用途

### 转换为 sGREEN，自动赚取收益

[sGREEN](../earning-and-rewards/01-sgreen.md) 是 GREEN 的生息搭档：

* **设置一次，坐享收益：** 存入 GREEN，获得 sGREEN。
* **兑换率增长：** 随收入到达，每枚 sGREEN 可赎回更多 GREEN；不会发生弹性供应。
* **协议收入：** 发起费和借款人利息。
* **即时流动性：** 随时赎回为 GREEN。
* **可叠加：** 稳定池接受 sGREEN。

### 参与稳定池

将 sGREEN 或 GREEN LP 代币存入[稳定池](../earning-and-rewards/02-stability-pools.md)：

* **三项收入来源：** sGREEN 收益、清算所得、RIPE 奖励。
* **低于市场价格的抵押品：** 资金池按资产清算价差买入被清算抵押品。
* **支持协议：** 您的存款使有序清算成为可能。
* **没有锁定：** 只要资金池持有欠您的资产，就可以提取相应价值。

### 提供多种借款接收选项

借款时，可以选择 GREEN 如何到达：

* **直接接收 GREEN：** 可用于任何用途。
* **自动转换为 sGREEN：** 立即开始赚取收益。
* **进入稳定池：** 直接进入资金池，从第一天开始赚取收益。

### 赚取 RIPE 区块奖励

通过 GREEN 赚取 [RIPE](../earning-and-rewards/03-ripe-rewards.md) 有多种方式：

* **借入 GREEN：** 贷款越大、持续越久，奖励越多。
* **稳定池存款：** sGREEN 和 GREEN LP 存款赚取 RIPE。
* **时间加权：** 积分按仓位规模 × 时间累积。
* **抵消成本：** 奖励可降低实际借款利率或提高资金池回报。

## GREEN 与竞品：明显胜出

**对比中心化稳定币（USDC/USDT）：** 您不能借入它们——只能买入。GREEN 以您已有资产为基础铸造，sGREEN 则在 USDC 闲置时继续赚取收益。

**对比传统加密稳定币（DAI/LUSD）：** DAI 为每类抵押品分别建立金库，LUSD 只接受 ETH。GREEN 用整个投资组合共同支持一笔贷款。

**对比算法稳定币实验（UST）：** 没有真实支持，崩溃难以避免。每笔 GREEN 贷款都超额抵押，也没有可能挤兑的出借人资金池。

**关键区别：** GREEN 为希望让整个投资组合发挥作用的借款人而建——一笔贷款，一个利率，一个需要关注的数字。

## 这为何重要

其他稳定币都迫使您取舍：安全还是效率，收益还是流动性，简单还是强大。

GREEN 打破这些取舍。一个仓位，由您拥有的一切共同支持；收益在睡眠中自动复利；别人爆仓时获得清算所得；六项机制维护锚定，而不是只靠信念。

不要再满足于为 2020 年设计的稳定币。这才是当今 DeFi 中资金应有的运作方式。
