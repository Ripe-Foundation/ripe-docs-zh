# 去杠杆：趁还来得及时降低风险

被清算的体验很糟糕：费用、被迫卖出、压力。

去杠杆提供了另一种选择：使用您已持有在 Ripe 中的 sGREEN 和稳定币仓位偿还债务。不收取清算费，也没有守护者费用。用自己的资产保护自己的仓位，而且不会动用股票代币。

> **实时条款以链上为准。** 哪些资产可用于去杠杆，以及相关缓冲和限制，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 快速概览

共有两种方式：**指定资产路径**（由您选择使用哪些资产以及偿还多少）和**通用路径**（不指定资产；进入赎回区后，其他人可对您执行去杠杆）。

**主要区别：**

| 方面 | 去杠杆 | 清算 |
| --- | --- | --- |
| 何时发生 | 指定资产路径：随时可以，清算期间也可以。通用路径：进入赎回区后 | 达到或超过清算阈值时 |
| 谁来触发 | 指定资产路径：您本人、获得 `canBorrow` 权限的委托人或受信任协议。通用路径：任何人 | 任何人（守护者） |
| 使用什么 | 您的 sGREEN 和稳定币仓位 | 股票代币、WETH 和其他波动性抵押品 |
| 费用 | 无 | 清算费 + 守护者费用 |
| 您的控制权 | 您选择资产和金额 | 由协议选择 |

从钱包支付 GREEN 属于普通还款，不是去杠杆。

## 何时可以执行去杠杆

### 使用指定资产自行去杠杆

您可以选择使用哪些 sGREEN 或稳定币仓位、使用顺序，以及要偿还多少债务。该方式随时可用：没有阈值，无需额外许可，即使正在清算也可以执行。获得您授予的 `canBorrow` 权限的委托人或受信任协议，也可以代您执行。

### 第三方去杠杆（赎回区）

当抵押品价值等于或低于赎回阈值后，任何人都可以通过通用路径对您的仓位执行去杠杆：

* 金额上限仅够把仓位恢复至健康状态，任何人都不能拿走更多。
* 仍不收取费用。
* 清算期间不可使用。

如果您对自己的账户调用通用路径，也会被视为第三方：必须进入同一赎回区，并受同一上限约束。请改用指定资产路径。

## 去杠杆如何运作

资产按固定顺序使用：

**第一阶段：您的稳定池仓位**

* **sGREEN** 赎回为 GREEN 并销毁。
* **LP 代币** 按预言机价值转入金库。
* 每 1 美元资产抵消 1 美元债务。

**第二阶段：稳定币抵押品**

* USDC 和其他稳定币按预言机价值转入金库。
* 不打折。

没有去杠杆路径的资产会被跳过。股票代币和其他波动性抵押品不会被使用，因此去杠杆是在保护股票仓位，而不是消耗它。（治理拥有两种可按预言机价值移动波动性抵押品的紧急工具——波动性资产去杠杆和抵押品兑换——且只有治理可以运行。）

结算前，Ripe 会再次读取您的债务；如果债务在交易期间发生变化，整笔交易都会回滚。

### 选择指定资产

```
示例：保留股票代币

您持有：
- 一种股票代币（15,000 美元）
- 10,000 USDC（10,000 美元）
- 稳定池中的 1,000 sGREEN（1,000 美元）

债务：12,000 美元

您执行去杠杆：
1. 先用 sGREEN  → 债务降至 11,000 美元
2. 再用 USDC    → 债务降至 1,000 美元
3. 股票代币     → 完全未动

结果：剩余 1,000 美元债务，股票代币保持不变
```

### 全额偿还缓冲与尾差

当您本人或受信任调用者清偿全部债务时，Ripe 可以比债务多取极少量抵押品，使还款金额准确落点；超出部分同时受到固定金额和债务比例上限约束，实际中只是舍入尾差。合约还包含在还款差一点未达到全额时豁免尾差的路径，但其上限出厂时设为零，因此除非治理启用，否则不会豁免任何金额。仓位属于 Underscore Earn 金库时，两者均不适用。

## 使用 [Underscore](https://underscore.finance/) 金库？

Underscore 金库自行管理其 Ripe 仓位，包括去杠杆。它如何借款、执行去杠杆，以及在您提取时如何调整，都取决于具体金库。详见 [Underscore Earn 金库集成](02-borrowing.md#underscore-earn-金库集成)。

## 去杠杆委托

* **`canBorrow`** 允许委托人使用指定资产代您执行去杠杆；这也是允许其借款的同一权限。
* 委托人可以选择资产、顺序和金额。
* 批量处理多个账户时，会分别检查每个账户的权限。

## 何时应去杠杆

不要等到清算。以下情况应考虑去杠杆：

* 波动性开始上升。
* LTV 接近警戒区。
* 您希望减少对某种资产的敞口。
* 您正在轮换抵押品。

## 去杠杆所处的位置

```
健康 → 警告 → 赎回区 → 清算区
  |       |        |          |
随时     随时    + 赎回      清算，且您仍可
去杠杆   去杠杆  + 通用去杠杆  自行去杠杆
```

* **赎回：** GREEN 持有人按 1 美元偿还您的债务，并按预言机价格取得抵押品。
* **去杠杆：** 您的 sGREEN 和稳定币用于偿债，不收取费用，并由您选择资产。
* **清算：** 收取费用的强制出售，是最后手段。

完整介绍请参阅[清算](04-liquidations.md)。

## 主动掌控风险

清算是最坏情况，去杠杆则是一件工具。

1. 监控仓位。
2. 在稳定池保留一些 sGREEN，或在仓位中保留稳定币；它们就是去杠杆的燃料。
3. 如果希望他人能采取行动，请设置委托。
4. 尽早去杠杆，不要等到最后。

始终领先于清算阈值，保持主动权。
