# 清算：只取一块，不端走整盘

大多数协议在您越过界线的瞬间就清算一切。仓位价值 10,000 美元，债务达到 9,001 美元？全部拿走。

Ripe 只取让仓位恢复健康所需的部分，其余仍归您所有。但必须如实说明上限：如果缺口严重，目标会变成您的全部债务，所有具备清算资格的抵押品都可能被取走，却仍不足以清偿全部债务。本页解释如何留在界线安全的一侧，以及越界后会发生什么。

> **实时条款以链上为准。** 资产、LTV、阈值、费用、拍卖设置及启用了哪些可选功能，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 内容摘要

**关键要点：**

* 🛡️ **先经过两个警戒区：** [去杠杆](05-deleverage.md)和赎回会在任何强制操作前给您留出空间。
* 📊 **只取一块，不端走整盘：** 清算以恢复健康所需的减债金额为目标，而不是整个仓位。
* 💰 **费用有上限：** 基础费用加守护者费用，每次清算过程只收取一次，并以抵押品盈余为上限。
* ⚡ **任何人都能触发：** 开放的守护者网络，以 sGREEN 获得报酬。
* 🚫 **稳定币和 sGREEN 不会在清算中卖出：** 它们用于[去杠杆](05-deleverage.md)。

**清算流程速览**

```
您的仓位开始下滑
        ↓
去杠杆（您本人，随时可以）
└─ 使用您的 sGREEN 和稳定币仓位偿还债务，不收取费用
        ↓
赎回区
└─ GREEN 持有人按 1 美元替您偿债，并按预言机价格取得抵押品
   没有折扣，没有费用
        ↓
清算阈值——任何人都能触发
        ↓
┌───────────────────────────────────────┐
│ 第一阶段：稳定池兑换                  │
│ • 股票代币、WETH 和其他波动性资产     │
│ • 资金池按清算价差买入                │
└──────────────────┬────────────────────┘
                   ↓（剩余部分）
┌───────────────────────────────────────┐
│ 第二阶段：荷兰式拍卖                  │
│ • 任何人都能使用 GREEN 购买           │
│ • 折扣随拍卖时间增长                  │
└───────────────────────────────────────┘
```

**这对您意味着：**

* ✅ 尽早去杠杆，清算永远不会开始。
* ✅ 保留无需用于恢复健康的抵押品。
* ✅ 不会直接砸盘：先进入资金池，再进入拍卖。
* ✅ 您的稳定币和 sGREEN 保持不动。

## 清算为何重要

### 保护协议偿付能力

每枚 GREEN 都以抵押品为基础铸造。当仓位抵押品下跌，或利息不断累积，直到债务不再得到覆盖，就必须有机制弥补缺口，否则 GREEN 会失去支持。清算就是这项机制。它的存在是为了保护 [GREEN](01-green-stablecoin.md) 及其所有持有人。

### 对借款人更友好的方式

系统通过目标金额弥补缺口，而不是清空仓位。Ripe 会计算需要偿还多少债务，才能让仓位回到安全 LTV，并且只取覆盖该金额所需的抵押品。

* **您保留其余部分**——达到目标无需使用的抵押品仍归您所有。
* **减少卖出**——清算规模更小，对资产价格的压力更低。
* **保留复苏空间**——仓位仍然存在，之后的价格反弹仍归您所有。
* **费用固定且有上限**——没有任意罚金。

## 了解风险区

### 三项关键阈值

每种资产都有三个数字，您的仓位会按[加权条款](02-borrowing.md#jia-quan-zhai-wu-tiao-kuan-xiang-jie)将它们分别合并成一个整体数值：

**1. 最高 LTV（贷款价值比）**

* 借款上限占抵押品价值的比例。
* 示例：价值 10,000 美元的抵押品，LTV 为 70%，最多可借 7,000 GREEN。
* 超过后，不能继续借款。

**2. 赎回阈值**

* 早期警告：GREEN 持有人可以替您偿还债务，并按预言机价格取得抵押品。
* 示例：77%。

**3. 清算阈值**

* 超过后，任何人都可以清算您的仓位。
* 示例：80%——债务为 8,000 美元时，抵押品价值降至 10,000 美元或以下即开放清算。

### 风险如何升级：分区图

示例：债务为 6,000 美元，抵押品起始价值 10,000 美元，采用 70% / 77% / 80% 阈值：

```
仓位健康情况（对应 6,000 美元债务）
←─────────────────────────────────────────────────────────────→
10,000 美元                 8,571 美元  7,792 美元  7,500 美元     0
  当前                       ↓          ↓          ↓
  仓位                    最高 LTV     赎回       清算
  在此                     （70%）     （77%）    （80%）

[════ 安全区 ════][警戒区][赎回区][清算区]
     ✅ 健康       ⚠️ 警告  🚨 危险  💀 严重
```

**🟢 区域 1：健康**（抵押品高于 8,571 美元）

* 低于最高 LTV，仍可借款。
* 没有人可以动用仓位。

**🟡 区域 2：警戒**（8,571–7,792 美元）

* 超过最高 LTV：不能新增借款，也不能提取，直到重新回到上限以内。
* 还没有人能动用您的抵押品。
* 请增加抵押品或还款。

**🟠 区域 3：赎回**（7,792–7,500 美元）

* GREEN 持有人可以赎回您的抵押品，第三方也可以对您执行[去杠杆](05-deleverage.md)。
* 两者都会按公允价值降低债务，不收取费用。

**🔴 区域 4：清算**（7,500 美元及以下）

* 任何人都可以触发清算。
* 开始收取费用。

阈值会因资产而异：稳定币类资产更高，波动性资产更低。_关于三项阈值如何合并，请参阅_ [_了解三项阈值_](02-borrowing.md#san-xiang-yu-zhi-ru-he-xie-tong-zhi-guan-zhi-nan)_。_

## 赎回缓冲区

### 您的第一道防线

进入赎回区后，如果治理已为某种资产启用赎回，任何 GREEN 持有人都可以针对您的仓位赎回：

* 他们按 1 美元支付 GREEN，并按预言机价格取得您的抵押品——没有折扣。
* 您的债务减少相同金额。
* 最高金额仅够把您恢复到目标状态，因此任何人都不能赎回超过仓位所需的部分。
* 它可能在清算开放前就把您带离赎回区。

还需遵守几项规则：抵押品不能发送回作为仓位所有者的您；带有接收方检查的资产只能发送给通过检查的地址；清算期间关闭赎回。注册的 Underscore Earn 金库会被赎回和清算同时跳过。

赎回也会在市场承压时帮助 GREEN 保持 1 美元。**想先主动行动？** 随时使用 sGREEN 或稳定币仓位执行[去杠杆](05-deleverage.md#shi-yong-zhi-ding-zi-chan-zi-xing-qu-gang-gan)。

## 清算过程

### 清算前：去杠杆

有两种完全不收取费用的减债方式：

* 从钱包**偿还 GREEN**，即普通还款。
* **[去杠杆](05-deleverage.md)：** 您的 sGREEN 稳定池仓位会赎回并销毁，稳定币抵押品则按预言机价值进入金库，每一美元资产抵消一美元债务。

您本人、获得 `canBorrow` 权限的委托人或受信任协议，都可以随时使用指定资产去杠杆，清算期间也可以。进入赎回区后，第三方可以对您执行去杠杆，金额上限仅够恢复健康。

**关键点：** 清算只处理具有稳定池或拍卖路径的资产。稳定币和 sGREEN 用于去杠杆，因此清算不会动用它们。

### 清算开始后会发生什么

当您达到或超过清算阈值，任何人都能触发清算（治理也有一个可暂停全部清算的总开关）。从此刻起：

1. **账户被冻结。** 不能新增借款，也不能提取（包括 LTV 为零的资产）。仍可还款，也仍可使用自己的 sGREEN 和稳定币仓位去杠杆。
2. **费用只设置一次。** 一次清算过程的基础清算费和守护者费用，会在第一轮计算。之后的重试轮次不收费——详见[清算经济机制](#qing-suan-jing-ji-ji-zhi)。
3. **抵押品按目标处理。** 先通过稳定池，再把剩余部分送往拍卖。无需用于目标的抵押品仍归您所有。
4. **进行中的拍卖占用本轮处理。** 只要您的一场拍卖仍在进行，下一轮清算就必须等待。拍卖到期后，任何人都可以清除它，让清算重新尝试（被治理暂停的拍卖会一直保留，直到治理清除）。

**如何退出。** 任何发现仓位已恢复健康的更新都会清除清算标志，并取消正在进行的拍卖。健康指债务不超过最高借款能力，因此还款、增加抵押品，或价格恢复后执行任意会重新检查仓位的操作，都符合条件。仅重新回到清算阈值之上还不够。

### 第一阶段：稳定池兑换

[稳定池](../earning-and-rewards/02-stability-pools.md)持有 sGREEN 和 LP 代币，随时准备买入被清算抵押品：

1. 您的股票代币、WETH 或其他波动性抵押品需要出售。
2. 资金池按清算价差买入；用于支付的 sGREEN 被销毁，LP 代币则进入金库。
3. 资金池存款人通过份额拥有这些抵押品。
4. 您的债务按资金池支付金额减少。

只有治理为某种资产启用该路径，资产才会进入资金池；资金池还必须接纳该资产并有足够容量，否则直接进入拍卖。带白名单的资产会通过专属许可资金池结算。资产可以只采用拍卖，或先资金池后拍卖；启用资金池路径时，拍卖始终作为后备。

重试轮次的基础费用为零，因此资金池按面值结算：没有价差。[稳定池](../earning-and-rewards/02-stability-pools.md)页面介绍存款人一侧。

### 第二阶段：荷兰式拍卖

资金池未买入的部分进入拍卖：

* 经过可选的开始延迟后，折扣从较小值逐步增长至拍卖窗口结束时的最高值。
* 除作为仓位所有者的您之外，任何持有 GREEN 的人都可按当前折扣购买任意数量，并立即结算。
* 他们的 GREEN 被销毁，您的债务减少相同金额。
* 每笔购买以剩余债务和剩余抵押品为上限。
* 抵押品售罄或仓位恢复健康时，拍卖结束；未售出抵押品留在您的金库中。

示例：起始折扣 1%，到窗口结束时上升至 50%。

### 股票代币

股票代币与其他波动性抵押品采用相同方式清算：启用资金池路径时先进入资金池，剩余部分再拍卖。缺口较小时只会取走一部分；缺口严重时可能全部取走。详见[哪些事件可以移动您的代币](00-stock-tokens.md#na-xie-shi-jian-ke-yi-yi-dong-nin-de-dai-bi)。

## 清算经济机制

### 了解清算费用

两项费用，每次清算过程只收取一次：

* **基础清算费**——按资产设置，再按借款能力在仓位中加权。示例层级：
  * 稳定币类：5%（不会在清算中出售；该比率只参与加权费用计算）
  * 蓝筹资产（WETH、WBTC）：10%
  * 波动性较高的资产：15%
* **守护者费用**——债务的一小部分，并设有最低和最高金额。示例：1%。

**上限。** 两项费用合计不得超过抵押品盈余（抵押品价值减去债务），也不得超过债务的 99%。如果超出，先减少守护者费用，再减少基础费用。如果抵押品价值已经低于债务，完全没有盈余，两项费用都为零。

**如何支付。** 稳定池采用不超过加权基础费用的折扣率买入；该折扣为资金池带来的价值会抵扣基础费用——最多抵扣至基础费用本身，绝不会更多。未被抵扣的基础费用加上守护者费用，会加入您的债务。重试轮次不收取费用；第一轮如果既没有偿还任何债务，也没有开启拍卖，同样不收费。

**价值去向**

1. **稳定池存款人**——以低于预言机价格取得抵押品。
2. **守护者**——获得守护者费用，默认铸造为 sGREEN（可要求 GREEN）。
3. **拍卖买家**——按当前折扣取得抵押品。
4. **金库**——接收资金池花费的 LP 代币；任何地方花费的 GREEN 都会被销毁。

### 部分清算设计

目标是把您恢复到安全 LTV 所需的减债金额。它根据实时债务加费用、抵押品价值、所有资产中的最低 LTV 以及还款缓冲计算。Ripe 只取覆盖目标所需的抵押品，不会多取。

示例：

```
债务：1,000 美元
抵押品：1,250 美元——已超过阈值
目标 LTV：50%
清算费：10%，无守护者费用

目标还款额 =（债务 + 费用 − 抵押品 × 50%）÷（1 − 50%）
           =（1,000 + 100 − 625 美元）÷ 0.5 = 950 美元

资金池支付 950 美元，取得价值 1,055.56 美元的抵押品（低于预言机价格 10%）。
债务降至 50 美元。剩余抵押品：194.44 美元——重新回到安全区内。
105.56 美元价差是资金池存款人的回报。它完全结算了
100 美元基础费用，因此没有任何费用加入您的债务。

其他协议：取走全部 1,250 美元。您得到 0。
```

如果缺口严重，目标会变成全部债务，所有具备清算路径的资产都可能被取走，却仍不足以清偿全部债务。

## 守护者网络

### 您的自动化安全网

守护者是独立运营方，持续监控仓位，并在越过界线时触发清算。任何人都能成为守护者，无需许可。

* 全天候监控仓位，并竞争最先执行。
* 获得以 sGREEN 铸造的守护者费用。
* 快速行动意味着在仓位仍有盈余时就完成处理，而这正是减少您损失的关键。

## 传统 DeFi 与 Ripe 对比

| 功能 | 传统 DeFi | Ripe |
| --- | --- | --- |
| **清算金额** | 整个仓位 | 只取恢复健康所需部分；缺口严重时才以全部债务为目标 |
| **警告机制** | 无 | 赎回区和去杠杆区 |
| **清算费** | 13%–50% 罚金 | 基础费加守护者费，最高不超过盈余 |
| **谁能买入** | MEV 机器人 | 任何人：先稳定池，再拍卖 |
| **主动选择** | 无 | 随时去杠杆，不收取费用 |
| **稳定币和 sGREEN** | 与其他资产一样被出售 | 通过去杠杆处理，而非清算 |
| **市场影响** | 直接砸盘 | 先资金池，再拍卖 |

## 如果出现坏账怎么办

被清算仓位中剩余的债务不会自动成为协议坏账；治理会另行记录坏账。记录后，[债券](../governance-and-economics/03-bonds.md)购买可以清理坏账；为此支付的 RIPE 是唯一可以使发行量超过全协议 10 亿上限的情况——由持有人共同承担缺口，而不是让 GREEN 缺乏支持。

## 不会毁掉生活的清算

在其他协议中，清算意味着从零开始。在 Ripe，您失去的是一块，仓位仍然存在，您还留在场内。有了去杠杆，通常连这一块都可以避免失去。

示例中的 194.44 美元，就是挫折与灾难之间的差别。协议并不是出于善意：活下来的借款人会继续借款、继续支付利息。您的成功就是协议的成功。
