# 借贷：整个投资组合，一笔贷款

存入股票代币，无需卖出任何代币，就能以它们作抵押借入 GREEN。再加入投资组合中的其他资产——WETH、稳定币、收益仓位——全部共同支持同一笔贷款。一个仓位，一个加权利率，一个需要关注的数字。

大多数借贷协议要求每种资产开一个金库。五种资产，五笔贷款，五项清算风险。Ripe 真正把您的投资组合当作一个投资组合。

> **实时条款以链上为准。** 资产、LTV、利率、费用、限制及启用了哪些可选功能，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 借款如何运作

您存入抵押金库的每种资产都会共同支持一笔 [GREEN](01-green-stablecoin.md) 贷款。借款能力等于每种资产价值乘以其 LTV 后的总和：

```
借款能力 = Σ（资产价值 × 资产 LTV）
```

有两类资产不计入：[稳定池](../earning-and-rewards/02-stability-pools.md)仓位永远不是抵押品；LTV 为 0% 的资产（例如锁定 RIPE）虽在账户中，但不增加借款能力。

Ripe 通过预言机层为每种资产定价。只要有任何一种借款抵押品没有可用价格，价格恢复前您就不能借款或提取——详见[价格缺失时会发生什么](00-stock-tokens.md#价格缺失时会发生什么)。

## 加权债务条款详解

当您持有不止一种抵押品时，条款会按每种资产在借款能力中的占比加权，而不是按原始价值加权。LTV 较高的安全资产，会让整体条款更接近自身数值。

**示例：**

```
股票代币：10,000 美元 × 60% LTV = 6,000 美元借款能力
WETH：     5,000 美元 × 70% LTV = 3,500 美元借款能力
稳定币：  10,000 美元 × 80% LTV = 8,000 美元借款能力

总借款能力 = 17,500 美元
```

```
股票代币权重：6,000 / 17,500 美元 = 34.3%
WETH 权重：    3,500 / 17,500 美元 = 20.0%
稳定币权重：  8,000 / 17,500 美元 = 45.7%

利率：股票代币 8%，WETH 7%，稳定币 5%
您的利率 =（8% × 34.3%）+（7% × 20.0%）+（5% × 45.7%）≈ 6.4%
```

赎回阈值、清算阈值和发起费也采用同一加权方式。

## 关键安全阈值

三个数字控制您的仓位。每个数字都因资产而异，并像利率一样加权合并。

**1. 最高 LTV——借款上限。** 最多可借入抵押品价值的相应比例。价值 10,000 美元的 ETH，LTV 为 70%，则最多借 7,000 美元。

**2. 赎回阈值——警戒区。** 当抵押品 ≤ 债务 ÷ 赎回阈值，GREEN 持有人可以按每枚 GREEN 1 美元偿还您的债务，并按预言机价格取得抵押品。没有折扣，也没有罚金——这是按公允价值强制降低杠杆，也是[清算](04-liquidations.md)前的警告。

**3. 清算阈值——危险区。** 当抵押品 ≤ 债务 ÷ 清算阈值，任何人都可触发[清算](04-liquidations.md)。Ripe 只取恢复仓位健康所需的部分。如果缺口严重，目标会变为全部债务，所有具备清算路径的抵押品都可能被取走。

### 三项阈值如何协同：直观指南

**示例：** 以 LTV 70%、赎回阈值 77%、清算阈值 80% 的 ETH 为抵押，债务为 6,000 美元：

```
抵押品价值（对应 6,000 美元债务）
←─────────────────────────────────────────────────────────────→
10,000 美元                 8,571 美元   7,792 美元  7,500 美元    0

[════ 安全区 ════][警戒][赎回区][清算区]
    ✅ 健康       ⚠️ 警告  🚨 危险  💀 严重

│                          │            │           │
│                          │            │           └─ 清算（80%）
│                          │            │               6,000 ÷ 0.80 = 7,500
│                          │            │
│                          │            └─ 赎回（77%）
│                          │                6,000 ÷ 0.77 = 7,792
│                          │
│                          └─ 最高借款 / LTV（70%）
│                              6,000 ÷ 0.70 = 8,571
│
└─ 当前抵押品：10,000 美元（覆盖率 167%）
```

**🟢 安全区（抵押品高于 8,571 美元）。** 仓位健康。总借款最高可达 7,000 美元，并可提取不需要用于担保债务的部分。提取会保留 1% 缓冲：只有在提取后债务不超过最高借款能力约 99% 时才可进行。

**🟡 警戒区（8,571–7,792 美元）。** 超过最高 LTV。不能新增借款，也不能提取——每次提取都会重新检查整个仓位，因此即使 LTV 为 0% 的资产也必须留在原处。请还款或增加抵押品。

**🟠 赎回区（7,792–7,500 美元）。** GREEN 持有人可以[赎回](04-liquidations.md#赎回缓冲区)您的抵押品，任何人也可以对您执行[去杠杆](05-deleverage.md)。请立即行动：还款、增加抵押品，或按自己的方式去杠杆。

**🔴 清算区（低于 7,500 美元）。** 任何人都可以触发清算。还款仍然有效，而且仍会改善仓位。

**清算状态中。** 清算一旦开始，账户会一直保留该状态，直到债务重新降到最高借款能力以内——无论通过哪种方式实现。可以还款、增加抵押品，或等待价格恢复后执行任何重新检查仓位的操作（例如存入、领取）。退出清算也会取消抵押品上仍在进行的拍卖。清算期间：不能新增借款，也不能提取，包括 LTV 为 0% 的资产。

### 从两个方向理解同一组数字

LTV 向前看（债务占抵押品的比例）。赎回和清算则向后看：在给定债务下，抵押品价值必须保持在哪条线以上。数字相同，只是从另一端读取。

| 阈值 | 界线位置 | 界线处覆盖率 | 界线处抵押品 |
| --- | --- | --- | --- |
| **最高借款** | 抵押品 ≤ 债务 ÷ 0.70 后不得新增借款 | 143% | 8,571 美元 |
| **赎回** | 抵押品 ≤ 债务 ÷ 0.77 后，GREEN 持有人可以赎回 | 130% | 7,792 美元 |
| **清算** | 抵押品 ≤ 债务 ÷ 0.80 后，任何人都可清算 | 125% | 7,500 美元 |

抵押品数值均以本节 6,000 美元债务为基础；应保持在界线之上，而不是正好落在线上。

利息会增加债务，市场下跌会减少抵押品价值，二者都会把仓位推向阈值。应关注覆盖率，而不只是资产价格。

## 动态利率

正常利率是抵押品组合的加权基础利率。其上还有一项动态调整，仅在 GREEN 的参考资金池承受脱锚压力时启用。大多数时候，您只支付基础利率。

**信号如何形成。** 每当有人使用协议，Ripe 都会记录参考资金池中 GREEN 占比的快照。信号是近期快照的按时间加权平均值，而且每两个快照之间的区间都采用两端较低的数值——因此单次尖峰无法提高您的利率。间隔过长的区间会从平均值中剔除；如果最新快照本身已过期，则完全没有信号，您只支付基础利率。

**超过触发点后会发生什么。** 当信号达到危险触发点（例如 GREEN 占比 60%）时，会应用两项加成：

1. **比例加成**——乘以基础利率。从触发点的最低值线性增长，到 GREEN 占比 100% 时达到最高值。
2. **危险加成**——按处于危险状态的区块数增加固定数值。只有区间两端都高于触发点时，危险时间才会增长；只有持续处于安全状态一段时间后才会重置。混合区间或过期区间既不会增加，也不会清除危险时间。

无论资金池失衡多久，总利率都受硬上限约束。

**示例：**

```
基础利率：                                  5%
GREEN 占比 70% 时的比例加成（基础利率的 100%）：+5%
长期处于危险后的危险加成：                    +0.5%
下次刷新前的利率：                           10.5%（受最高利率限制）
```

**何时应用于您。** 利率存储在贷款上，只会在您借款、还款或仓位重新检查（存入、提取或领取）时刷新。资金池变化本身不会改写闲置债务——无论上调还是下调都不会。

### Underscore Earn 金库集成

[Underscore](https://underscore.finance/) Earn 金库是自动化收益策略。部分金库会在策略内部从 Ripe 借入 GREEN；注册的 Earn 金库享有特殊借款条款：

* 加权利率获得治理设置的折扣。
* 不收取发起费。
* 不进行动态利率调整。
* 不参与清算和赎回。

**示例：** 标准利率 6%，Earn 金库享受 50% 折扣后为 3%，发起费为 0%。

这些条款跟随借款地址。金库自己借款时可以享受；您把某个 Earn 金库份额存作抵押品时不能享受。您获得的收益来自该金库策略，并受金库自身条款约束。

## 借款限制

每笔借款必须同时满足以下各项，并以最严格的限制为上限：

* **抵押品容量**——各资产价值 × LTV 之和，减去已有债务。
* **单用户债务上限**——对每个账户采用同一上限。
* **全局借款人债务限制**——限制借款人总债务；它限制新增借款，而不是 GREEN 总供应量。
* **借款人数上限**——可阻止新账户开启第一笔贷款，不影响现有借款人。
* **区间限制**——限制每个区块窗口内可借金额，避免单一用户瞬间耗尽容量。
* **最低债务**——新贷款或增加贷款的下限，避免出现微小仓位。

如果治理启用了每区块一次操作保护，较高风险的操作——提取、借款、稳定池领取和提前解除治理锁定——每个账户每区块只能进行一次。您执行的每项操作都会占用该时隙，而不只是上述四种操作，因此同一区块较早进行的存入或还款，也会让之后的提取或借款失败。

## 借款体验

1. 将抵押品存入 Ripe。
2. 在可用容量范围内借款。
3. 支付发起费——一次性费用，采用与利率相同的加权方式。
4. 选择接收方式。

### 发放选项

* **GREEN 进入钱包。** 最灵活的选择——可以兑换、使用或持有。
* **sGREEN。** 贷款在同一笔交易中包装为 [sGREEN](../earning-and-rewards/01-sgreen.md)，立即开始赚取收益。如果 sGREEN 收益高于借款利率，您会获得正利差。
* **sGREEN 进入稳定池。** 一步包装并存入首选[稳定池](../earning-and-rewards/02-stability-pools.md)：同时获得 sGREEN 收益、清算所得和 [RIPE 奖励](../earning-and-rewards/03-ripe-rewards.md)。流动性最低，但参与的机制最多。

包装会跳过尾差——小到无法包装的部分会以普通 GREEN 到账。

### 发起费

每次新增借款收取一次，从实际接收金额中扣除。这是协议收入：默认全部进入 sGREEN 持有人；治理也可以把一部分分配给治理。Earn 金库免收。

**示例：** 发起费 0.25%。借入 10,000 GREEN → 费用 25 GREEN → 您收到 9,975 GREEN，债务为 10,000。

## 还款

按自己的时间安排还款。

* **没有固定期限，也没有罚金。** 只要抵押品足以覆盖贷款，就可以一直持有；可随时偿还。
* **可以部分还款。** 每笔付款都会立即降低债务和风险。
* **直接从钱包使用 GREEN 或 sGREEN 还款。** 多付部分默认以 sGREEN 退还。应用的 MAX 按钮会使用您的全部余额，并退回不需要的部分。
* 如果已启用 `canAnyoneRepayDebt`，**他人可以代您还款**。默认关闭。

全额还清是成本最低的交易：债务归零后，没有需要重新检查的仓位。

## 真正理解投资组合的一个仓位

不再为每种资产开一个金库，也不再让抵押品闲置。股票代币、ETH 和稳定币以一个加权利率共同支持一笔贷款，在任何强制操作前还有两个警戒区。如果 GREEN 需要维护，您的利率会上升——但有上限；不需要时，您只支付基础利率。
