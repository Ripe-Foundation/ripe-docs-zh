# RIPE Reserve Engine：随时间归属的 RIPE

Reserve Engine 是直接从协议购买 RIPE 的第二种方式。预先付款，选择归属期限，获得一个随时间解锁 RIPE 的仓位——等待越久，配额越大。购买时，付款会立即进入[金库](../core-protocol/07-endaoment.md)；只有在领取时，相应 RIPE 才会被铸造。

[债券](03-bonds.md)即时结算，并可用于清理坏账。Reserve Engine 两者都不做；它有独立的定价、加成和预算。

> **实时条款以链上为准。** Reserve Engine 并非部署在所有网络。部署它的网络中，支付代币、纪元容量、兑换率、归属期限范围、加成和预算会各不相同，也会随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 购买流程

1. **预览。** 输入支付金额和归属期限。系统会给出报价：基础 RIPE、期限加成、总额、当前纪元兑换率，以及仓位何时开始可领取、何时完全归属。
2. **购买。** 交易会携带报价对应的纪元、归属期限、最低 RIPE 输出量和截止时间。如果纪元已经切换、总额低于您的最低要求，或截止时间已过，交易会回滚——不会部分成交。
3. **创建仓位。** 付款进入金库，完整配额（基础部分加期限加成）从预算中预留，并以您的名义记录一个归属仓位。此时尚未铸造任何 RIPE。

仓位属于购买者。您不能替他人购买，仓位也不能转让。

## 定价：纪元与控制器

时间被划分为固定区块数的纪元。每个纪元拥有一个基础兑换率（每枚支付代币可得多少 RIPE）、支付容量、最低购买额和归属期限范围。这些条款由该纪元的**第一笔购买**锁定：第一笔购买前的配置变更适用于当前纪元；之后的变更要等到下一个纪元。

在纪元之间，控制器会根据前一纪元的需求，在治理设定的范围内调整基础兑换率：

* **高利用率**（该纪元大部分售罄）→ 下一纪元每枚支付代币获得的 RIPE 更少。需求在纪元中出现得越早，调整幅度越大。
* **低利用率** → 每枚支付代币获得更多 RIPE。
* **空闲纪元**（没有任何购买）→ 每经过一个空闲纪元，兑换率就阶梯式回升，直至上限。

治理还可以为即将开始的某个纪元指定准确的基础兑换率，仅在该纪元覆盖控制器。系统同时设有总上限：基础兑换率加上最长归属期限的加成，不得超过治理设定的综合兑换率上限。

## 期限加成

您可以选择该纪元最低与最高归属期限之间的任意长度。超过最高期限会被截断至最高值；低于最低期限或未填写则采用最低值。加成为线性计算——最低期限加成为零，最高期限获得全部加成——先以基础 RIPE 为基数计算，再加入配额。

```
示例：每枚 USDC 可得 4 RIPE，最低 3 个月，最高 12 个月，最高加成 50%

10,000 USDC，归属 3 个月  → 40,000 基础 + 0      = 40,000 RIPE
10,000 USDC，归属 12 个月 → 40,000 基础 + 20,000 = 60,000 RIPE
```

## 两项限制

* **纪元容量**限制一个纪元最多接受多少支付代币。
* **配额预算**限制所有 Reserve Engine 仓位总共可以预留多少 RIPE。每笔购买的完整配额都必须能放入预算；领取不会补回预算。

两者都不是托管的 RIPE，而是记账限制。通过它们铸造的所有 RIPE 都计入协议范围内的[10 亿供应上限](01-ripe-tokenomics.md#供应上限全协议共计-10-亿)。

## 归属：追赶式悬崖期

每个仓位记录三个区块高度：

```
创建区块 = 购买所在区块
领取起点 = 创建区块 + 该纪元的最低归属期限
到期区块 = 创建区块 + 您选择的归属期限
```

RIPE 从创建到到期线性归属，但在领取起点前不能领取任何部分。到达领取起点时，此前已经归属的 RIPE 会一次性变为可领取——这是追赶式释放，而不是延迟开始归属。如果选择最低期限，领取起点和到期区块相同，届时全部配额一次到账。

**示例：** 选择 12 个月归属，最低期限为 3 个月。前三个月不能领取；三个月时约四分之一配额会立即变为可领取，其余部分继续归属至第 12 个月。

## 领取

任何仓位中只要已有归属的 RIPE，就可以领取。共有两种方式：

* **直接领取**——RIPE 铸造到您的钱包。
* **自动存入**——RIPE 在一步操作中铸造并锁入[治理金库](02-governance.md)，锁定期限由您提出（金库会应用自己的最低和最高期限）。

仓位存放在归属合约中；领取会通过当时在协议中注册的引擎执行，不一定是您最初购买时使用的那一个。

## 暂停

引擎和归属合约可以分别暂停：

* **引擎暂停**（或关闭购买）：不能进行新购买，领取仍可继续。
* **归属合约暂停：** 不能领取，也不能进行新购买。

铸造权限和 RIPE 代币自身的暂停状态位于二者之上：如果不能铸造 RIPE，就无法完成任何结算。在代币层面被阻止的受益人也无法领取。

## 购买前须知

* 预览只是报价，不是预留。执行时会重新检查。
* 请选择愿意等待到底的归属期限。没有提前退出机制。
