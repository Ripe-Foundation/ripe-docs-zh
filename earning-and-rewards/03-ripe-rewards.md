# RIPE 奖励：使用协议，也能获得报酬

每个区块。每个仓位。每一美元借款或质押。

Ripe Protocol 都在记录，并支付奖励。

2.5 亿 RIPE——总供应量的四分之一——通过区块奖励和债券留给真正使用协议的人。不是风险投资机构，不是内部人士，而是用户。借入 GREEN？获得报酬。参与质押？获得更多。锁定奖励？获得更多。

> **实时条款以链上为准。** 释放速率、类别分配、资产权重、自动质押比例和锁定条款，会因部署而异并随时间变化。本页所有数字均为示例。[Params](https://params.ripe.finance) 才是权威来源。

## 快速入门：了解您的奖励

**🎯 一分钟读懂：**

```
您的活动                    → 类别（示例分配）          → 您的份额
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
质押 RIPE / RIPE LP        → 质押者             90%    → 所在池份额 × 您的积分占比
存入 sGREEN / GREEN LP     → 质押者             90%    → 所在池份额 × 您的积分占比
借入 GREEN                 → 借款人             10%    → 您的借款积分 ÷ 全部借款积分
存入其他任何金库资产        → 普通存款人          0%     → 美元价值 × 时间（启用前为关闭）
由投票选出的资产            → 投票者              0%     → 社区决定（启用前为关闭）

积分 = 余额 × 区块数。您在池中的份额 = 您的积分 ÷ 该池总积分。
```

**💡 关键洞察：** 您无需与所有用户竞争，只与自己所在池中的用户竞争。借款人不会稀释质押者；sGREEN 存款人也不会稀释 RIPE LP 质押者。

## 奖励引擎

### 每个区块都算数

奖励不会按周度纪元发放。每个区块都会从奖励额度中向奖励池增加固定数量的 RIPE，再按四个类别的权重进行分配。权重会归一化：90/10/0/0 表示质押者获得每个区块释放量的 90%，借款人获得 10%。

领取前不会铸造任何代币。您的应得奖励会从额度中持续累积；只有在领取的那一刻，代币才真正产生。

还有两类支出使用同一奖励额度：领取[稳定池](02-stability-pools.md)资产时支付的 RIPE（见下文），以及治理启用后定期向 Underscore 钱包用户分发的 RIPE。

### 积分系统

```
积分 = 余额 × 持有区块数
```

公式就是这么简单。较小仓位持有更久，可以超过巨鲸短暂进入所赚的奖励。这是由数学实现的公平。

每个金库与资产组合都是独立资金池，拥有自己的积分总数。同一种代币存放在两个不同金库，会在两个池中分别赚取奖励。

## 奖励类别

### 1. 质押者（示例中为 90%）💎

[**治理金库**](../governance-and-economics/02-governance.md) **（RIPE 和 RIPE LP）**

* **锁定乘数：** 锁定越久，积分加成越高——最长锁定可达到 3 倍。该加成已经包含在您的积分占比内。
* **LP 优势：** RIPE LP 有自己的资产权重，而且在示例中权重最高。
* **复利：** 领取的奖励会重新质押到金库，因此奖励也会继续赚取奖励。

[**稳定池**](02-stability-pools.md) **（[sGREEN](01-sgreen.md) 和 GREEN LP）**

* **三重收益：** sGREEN 收益、清算所得，再加上 RIPE。
* **无需锁定：** 只要资金池允许，随时可以提取。
* **领取奖励：** 从资金池领取被清算抵押品时，每领取 1 美元资产会额外获得 RIPE。该 RIPE 100% 进入治理金库，并按奖励锁定期限锁定；没有流动部分。

### 2. 借款人（示例中为 10%）💰

借入 GREEN 后，您的本金每个区块都会赚取积分：

* **积分：** 未偿本金 × 借款区块数。
* **您的份额：** 您的借款积分 ÷ 全部借款积分。
* **实际好处：** RIPE 收益可以抵消部分利息。

### 3. 普通存款人（示例中为 0%）

治理可以为所有其他金库存款启用奖励，权重按美元价值 × 区块数计算。只有未作为质押者获得奖励的资产才符合资格。

### 4. 投票者（示例中为 0%）

治理可以通过投票将奖励引导至特定资产，把流动性导向协议需要的地方。

## 了解您的份额

### 资产权重

在质押者类别中，每种资产都有一个权重。示例：

* RIPE LP：45
* GREEN LP：25
* sGREEN：15
* RIPE：15

这些是权重，不是固定百分比。每个资金池每个区块都会按自身资产权重累积类别积分，而某个池在类别中的份额 = 该池积分 ÷ 全部类别积分。如果只有这四个池且权重保持不变，其份额将分别为 45% / 25% / 15% / 15%。

### 奖励实际如何流动

```
RIPE 总释放量（示例中为每天 500 RIPE）
            ↓
    ┌───────┴───────┐
    │   第一次分配   │（按类别权重）
    └───────┬───────┘
            ↓
    90% → 质押者
    10% → 借款人
     0% → 普通存款人、投票者
            ↓
    ┌───────┴───────┐
    │   第二次分配   │（类别内各资金池）
    └───────┬───────┘
            ↓
    每个池的份额 = 该池积分 ÷ 类别积分
            ↓
    您的份额 = 您的积分 ÷ 该池积分
```

借款人会跳过第二次分配：您的借款积分 ÷ 全部借款积分，到此结束。

### 分步计算指南

**🎯 第 1 步：属于哪个类别？**

```
质押 RIPE、RIPE LP、sGREEN 或 GREEN LP → 质押者（90%）
借入 GREEN                              → 借款人（10%）
```

**🎯 第 2 步：您的池占多少？**

```
每天 500 RIPE，每枚 10 美元 = 每天 5,000 美元
质押者：每天 450 RIPE    借款人：每天 50 RIPE

质押者内部（每天 450 RIPE）：
- RIPE LP   45% = 每天 202.5 RIPE
- GREEN LP  25% = 每天 112.5 RIPE
- sGREEN    15% = 每天  67.5 RIPE
- RIPE      15% = 每天  67.5 RIPE
```

**🎯 第 3 步：您在池中占多少？**

```
您的积分 = 余额 × 区块数
您的份额 = 您的积分 ÷ 资金池积分

示例：质押 1,000 RIPE，共 100 个区块
- 您的积分：1,000 × 100 = 100,000
- 资金池积分：1,000,000
- 您的份额：10%
```

**🎯 第 4 步：计算您的奖励**

```
10% × 每天 67.5 RIPE = 每天 6.75 RIPE
每枚 RIPE 10 美元 = 每天 67.50 美元
```

### 简易奖励估算器

假设：每天释放 500 RIPE，每枚 RIPE 价值 10 美元，并采用上述权重。“积分占比”指您的积分 ÷ 该池积分；如果所有人的持有时间相同，则积分占比等于余额占比。

**RIPE LP（质押者类别的 45%）：**

```
每日 RIPE ≈ 您在 RIPE LP 池的积分占比 × 202.5

示例：价值 100,000 美元的 RIPE LP，积分占比 1%
= 1% × 202.5 = 每天 2.025 RIPE = 每天 20.25 美元
= 约 7.4% APR
```

**GREEN LP（质押者类别的 25%）：**

```
每日 RIPE ≈ 您在 GREEN LP 池的积分占比 × 112.5

示例：价值 100,000 美元的 GREEN LP，积分占比 1%
= 1% × 112.5 = 每天 1.125 RIPE = 每天 11.25 美元
= 约 4.1% APR
```

**RIPE 质押（质押者类别的 15%）：**

```
每日 RIPE ≈ 您在 RIPE 池的积分占比 × 67.5

锁定乘数已经包含在您的积分占比中：
锁定 3 年的 10,000 RIPE，积分按 30,000 枚未锁定 RIPE 计算。

示例：10,000 RIPE（价值 100,000 美元），锁定 3 年，积分占比 3%
= 3% × 67.5 = 每天 2.025 RIPE = 每天 20.25 美元
= 约 7.4% APR；按日复利约 7.7% APY
```

**sGREEN（质押者类别的 15%）：**

```
每日 RIPE ≈ 您在 sGREEN 池的积分占比 × 67.5

示例：价值 100,000 美元的 sGREEN，积分占比 2%
= 2% × 67.5 = 每天 1.35 RIPE = 每天 13.50 美元
= 约 4.9% APR
```

**借入 GREEN（释放量的 10%）：**

```
每日 RIPE ≈ 您的借款积分 ÷ 全部借款积分 × 50

示例：借款 500,000 美元，积分占比 5%
= 5% × 50 = 每天 2.5 RIPE = 每天 25.00 美元
= 约相当于返还 1.8% APR 的利息成本
```

## 领取奖励

### 领取时会发生什么

1. 协议汇总您在每个金库和每种资产中的积分，再加上借款积分。
2. 计算您在每个类别中的份额，并铸造相应数量的 RIPE。
3. 开启 **Stake All** 会将全部领取金额存入[治理金库](../governance-and-economics/02-governance.md)（直接调用合约时，这也是默认行为）。
4. 关闭 Stake All，您会收到流动部分，其余部分按自动质押比例处理——示例中为 75% 质押、25% 进入钱包。

自动质押的 RIPE 会采用奖励锁定期限：即金库锁定期限范围的一个比例，示例中为 33% × 3 年 ≈ 1 年。它会与现有治理仓位混合，可能改变您的解锁日期——详见[管理仓位](../governance-and-economics/02-governance.md#管理您的仓位)。

**领取示例：** 应得 1,000 RIPE。开启 Stake All：1,000 RIPE 全部锁入治理金库。关闭 Stake All：750 RIPE 锁定，250 RIPE 进入钱包。

**委托：** 授予 `canClaimLoot` 权限后，他人可以代您领取——适合自动复利。

**延后领取：** 如果您赚取奖励的某个类别暂时没有可支付金额，本次领取会结算为零并保留您的积分。不会损失任何东西；稍后再次领取即可。

### 为何自动质押

自动质押避免奖励代币直接涌入市场，并建立一个既有投入、又能随奖励积累治理权的参与者社区。您赚取的不只是代币，也是对协议未来的发言权。

## 奖励常见问题

### “为什么要计算两次份额？”

可以把它看作一次计算的两个输入：您从哪个蛋糕取食（所在资金池占类别的份额），以及您这一片有多大（您在池中的积分占比）。就像自助餐把甜点和主菜放在不同桌上——您只与同桌的人竞争。

### “同一类别中的不同资产会竞争吗？”

只在资金池层面竞争。RIPE 质押者与其他 RIPE 质押者争夺 RIPE 池份额；RIPE LP 质押者与其他 RIPE LP 质押者争夺 RIPE LP 池份额。各资金池本身的份额来自资产权重。

### “如果没有人质押或借款会怎样？”

参与者获得更多。如果只有您一人质押 RIPE，就获得 RIPE 池的全部份额。没有参与者的类别会保留其 RIPE，不会转给其他类别。

## 早起的鸟儿获得 RIPE

您在类别中的份额取决于自己的积分相对于所有其他人的积分。目前，其他人仍只是一个小群体。随着存款和借款增长，每位参与者的份额会缩小——上面示例中的 7.4% 是小资金池阶段的数字。

协议会奖励最先到场的人。您到场了吗？
